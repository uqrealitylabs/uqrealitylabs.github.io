# Search and AI discovery

The implemented foundation is crawlable static React HTML, real links, unique page titles and descriptions, reciprocal English/Spanish alternates, canonical URLs, a generated sitemap, public robots rules and structured data that matches visible content
Draft lore and unfinished policy text are labelled and excluded from indexing and the search index
The original favicon remains authoritative

Google’s current [AI features guidance](https://developers.google.com/search/docs/appearance/ai-features) says there are no additional requirements or special optimisations for AI Overviews or AI Mode
Existing SEO fundamentals still apply, and indexing and serving are not guaranteed
`llms.txt` is a useful public reading guide, not a Google requirement or a ranking promise
Search access remains allowed while the separate training-crawler policy reserves training rights
